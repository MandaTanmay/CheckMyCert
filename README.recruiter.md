# CheckMyCert

CheckMyCert is a full-stack certificate verification platform that helps detect forged credentials using OCR extraction, tamper analysis, and database-backed validation.

## Why this project is strong for Full Stack roles

- Built a complete web product across frontend, backend, async workers, and database.
- Implemented API-driven architecture with Next.js and Django REST Framework.
- Added scalable async processing with Celery and Redis for heavy verification jobs.
- Shipped role-based workflows, dashboards, and bulk processing features.
- Containerized the stack with Docker Compose for reliable local setup.

## Stack

- Frontend: Next.js 14, React 18, TypeScript, Tailwind CSS
- Backend: Django REST Framework, JWT auth
- Data and Queue: PostgreSQL, Redis, Celery
- OCR and Verification: OpenCV, EasyOCR, OCR.space
- DevOps: Docker, Docker Compose

## Key outcomes

- Supports single and bulk certificate verification flows.
- Provides result tracking and status updates for async verification.
- Enables QR/token lookup and role-specific verification operations.
- Demonstrates practical full-stack engineering and deployment readiness.
